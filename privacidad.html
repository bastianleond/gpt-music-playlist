gpt-music-playlist

Política de privacidad

Última actualización: 13 de noviembre de 2026.

Datos y finalidad

Con la autorización del titular, la aplicación consulta los nombres e identificadores de sus listas de YouTube para localizar la lista privada configurada. Lee los títulos, canales e identificadores de las pistas de esa lista para evitar duplicados. Usa los identificadores de canciones seleccionadas para agregarlas mediante la API de YouTube.

Almacenamiento y acceso

La aplicación conserva el identificador de la lista y la credencial de autorización en un archivo cifrado asociado a la cuenta de Windows del titular. La tarea de Codex puede leer los datos de la lista durante la ejecución y mostrar al titular las canciones agregadas. Google recibe las consultas y los agregados a través de su API y trata esos datos según su Política de Privacidad.

En la ejecución en la nube, la autorización y el identificador de la lista se guardan en un secreto de GitHub Actions en un repositorio privado del titular. La bitácora privada guarda identificadores de videos, fechas y estados para impedir que se vuelvan a agregar canciones retiradas. La tarea consulta los metadatos de YouTube cuando compara versiones. Los resultados de cada ejecución se muestran en GitHub Actions.

Este sitio informativo está alojado en GitHub Pages. GitHub puede registrar datos técnicos de las visitas según su declaración de privacidad.

Revocación y eliminación

El titular puede revocar el acceso desde las conexiones de su cuenta de Google y eliminar el archivo local de autorización, el secreto y el repositorio privado con la bitácora. Las pistas agregadas se gestionan desde YouTube Music. Para consultas de privacidad, puede usar el contacto de asistencia que figura en la pantalla de autorización de Google.

El uso de información recibida de las API de Google se ajusta a la Política de datos de usuarios de los servicios de API de Google, incluidos los requisitos de uso limitado.
